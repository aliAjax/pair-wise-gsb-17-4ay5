# hxwl-03 岩土钻孔编录

钻孔分层、标贯与地下水位的现场记录面板：可复查的编录流程。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

- 每孔按孔深顺序追加分层：新层起点必须接住上一层终点，重叠或留空当场提示，原分层表保持不变
- 分层补录：岩性、土色、标贯击数可先空后补，缺项在表内实时标出；末层可删除
- 地下水位：初见、稳定各记一次；稳定水位量测时间不能早于初见水位
- 终孔校验：达到设计孔深，且每层岩性、土色、标贯齐全后才能提交终孔
- 终孔纠正：原值、新值、纠正原因写入同一条追溯记录，终孔记录可复查
- 本机保存：localStorage 持久化，刷新不丢失

## 代码结构（四层分离）

- `src/types.ts` — 资料结构：钻孔、分层、水位、终孔记录、纠正追溯
- `src/rules.ts` — 规则判断：分层衔接、水位先后、终孔条件等纯函数校验
- `src/storage.ts` — 本机保存：localStorage 读写与示例数据
- `src/App.tsx` + `src/components/` — 页面：钻孔列表、分层表、水位卡片、终孔与纠正
