# hxwl-03 岩土钻孔编录

钻孔分层、标贯与地下水位的现场记录面板：按孔深顺序追加分层、记录地下水位、核查终孔条件、终孔后纠正留痕。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 目录结构（四层分离）

```
src/
  domain/
    types.ts    资料结构：钻孔、分层、水位、终孔与追溯记录
    rules.ts    规则判断：纯函数，校验失败返回错误且不产生新数据
    storage.ts  本机保存：localStorage 读写与示例数据恢复
    seed.ts     示例钻孔（在编 / 缺项 / 已终孔含纠正记录）
    format.ts   深度与时间显示格式化
  components/   页面：钻孔列表、分层表、水位卡、终孔与纠正面板
  App.tsx       组装与状态流转
```

## 编录流程与规则

- **分层追加**：新层起点必须等于上一层终点（首层为 0）；重叠或留空时输入即提示，提交被拒绝且原分层表不变。层的深度区间不可回改，岩性、土色、标贯可先空后补。
- **地下水位**：初见、稳定各记一次；稳定水位时间不得早于初见时间。
- **终孔**：当前孔深达到设计孔深，且每层均有岩性、土色、标贯结果后，提交按钮才可用；提交后分层与水位锁定。
- **纠正留痕**：终孔后可纠正终孔深度与水位，原值、纠正值、原因、时间写入同一条追溯记录。
- **本机保存**：所有变更自动写入 localStorage，刷新不丢；侧边栏可一键恢复示例数据。
